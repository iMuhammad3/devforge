# DevForge 🚀

DevForge is an interactive platform designed to help beginners learn programming from the ground up while giving experienced developers a place to revisit and strengthen core computer science concepts.

It focuses on teaching theory with plans to later add structured lessons with practical examples, coding challenges, quizzes, and real projects to help learners build confidence through practice.

---

## ✨ Features

- 📚 Beginner-friendly programming courses
- 💻 Interactive coding examples
- 🧠 Quizzes to reinforce learning
- 🌙 Modern responsive UI
- 🔐 Firebase Authentication
- ☁️ Cloud-hosted backend services

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/devforge.git
cd devforge
```

### Install dependencies

```bash
npm install
```

### Create an environment file

Create a `.env.local` file in the project root.

```env
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=
```

### Start the development server

```bash
npm run dev
```
